EXPERIMENTAL! NOT ON MAIN WEBSITE

IMPORTANT: This version of Muffin is for MacOS. There is no version of ```muffin-make``` or ```muffin-gui``` available for MacOS!

This allows the execution of pre-built MPA files on MacOS, with Python being the only dependency.

You can copy the file and execute it:

```
curl -fsSL https://raw.githubusercontent.com/AstroMeYT/muffin/refs/heads/main/install-full.sh && chmod +x muffin && muffin

```
