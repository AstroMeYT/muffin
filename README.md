IMPORTANT: This version of Muffin is for Windows. There is no version of ```muffin-make``` or ```muffin-gui``` available for Windows!

This allows the execution of pre-built MPA files on Windows 10/11, with Python being the only dependency.

One-command install:

```CMD

curl -fsSL https://raw.githubusercontent.com/AstroMeYT/muffin/refs/heads/windows/muffin-installer.bat -o "%temp%\muffin-install.bat" && "%temp%\muffin-install.bat"

```
